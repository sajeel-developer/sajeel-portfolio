Sajeel Portfolio

How to open:
1. Open index.html in Chrome/Edge.
2. Keep the assets folder beside index.html.
3. To publish for free, upload this folder to GitHub Pages, Netlify, or Vercel.

Included:
- Responsive single-page portfolio
- Animated profile photo / orbit effect
- Typing animation
- Scroll reveal animation
- Experience timeline
- Project cards
- LinkedIn and email links
